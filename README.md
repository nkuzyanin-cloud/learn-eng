# Afterhours — вечерний английский

Автономное веб-приложение: 82 эпизода, правила, практика, разговорная речь, профиль и коллекция плюшевых игрушек. Работает без сборки, npm и API-ключей. Раздел игры удалён.

## Обновление существующего проекта

Архив содержит **полный актуальный проект**, файлы лежат в его корне. Замените содержимое репозитория, сохраняя папки `assets` и `docs`. Если загружаете поверх старых файлов через GitHub, удалите также перечисленные в [docs/CLEANUP.md](docs/CLEANUP.md) игровые файлы и папки: загрузка новых файлов сама их не удалит.

Адрес опубликованного приложения должен остаться прежним: учебный прогресс хранится в браузере и привязан к адресу. Обновление удаляет игровые данные из сохранения, сохраняя уроки, XP, попытки, записи, достижения и выданные игрушки. Очистка данных сайта для обновления не требуется. Для резервной копии есть экспорт в настройках.

Список файлов офлайн-кэша и его версия обновлены. После загрузки новой версии service worker удаляет прежний кэш этого приложения. Если открытый экран ещё показывает старую версию, повторно откройте приложение после обновления.

## Запуск

Для GitHub Pages загрузите содержимое архива в репозиторий и включите публикацию выбранной ветки в **Settings → Pages**. Все пути относительные, поддерживается размещение в подпапке репозитория. Если браузер GitHub ограничивает число файлов за одну загрузку, загружайте папки частями.

Для локального просмотра: `python3 -m http.server 8000` в папке проекта, затем `http://localhost:8000`. Service worker работает через HTTP на localhost или через HTTPS; открытие `index.html` как `file://` не включает офлайн-режим.

## Обучение

Порядок и исходные сцены основаны на Let’s Learn English Level 1 (52 урока) и Level 2 (30 уроков). Объяснения и тренировки адаптированы для приложения; справочник использует материалы British Council и Cambridge. Источники и условия использования: [docs/SOURCES.md](docs/SOURCES.md). Карта источников и ключи исходных вопросов сохранены в `docs/source-map.json` и `docs/quiz-key.json`.

- Каждый новый эпизод: повторение предыдущей темы (3 вопроса, когда есть предыдущий пройденный урок), теория, упражнения, собственная история.
- Дневного ограничения нет: следующий эпизод можно начать сразу после завершения предыдущего. Повторение, практика и разговорная речь доступны в своём темпе.
- В текущем потоке — 650 заданий. 718 прежних заданий сохранены для совместимости старых попыток и начислений XP; их индексы не менялись.
- 65 подробных статей с правилами открываются по пройденным темам.
- Отдельная практика: разминка, аудирование, исправление фразы, переформулирование; 325 упражнений в банке справочника. Наборы по эпизодам — 82 × 4 задания.
- Разговорная речь готовит сообщение с изученными правилами для практики в отдельном чате; встроенной языковой модели нет.
- Собственные истории сохраняются без автоматической оценки грамматики. Они доступны через настройки → «Мои записи из уроков».
- 76 локальных записей сцен доступны без сети после заполнения кэша. Для синтеза речи используется голос устройства; скорость регулируется прямо в задании. Полные записи по внешним ссылкам требуют интернет.

Метки A1–A2 и A2–B1 — ориентир сложности материала, а не официальная оценка уровня. Точку старта можно изменить в настройках.

## Прогресс и коллекция

XP начисляется за учебное задание один раз, повторение не увеличивает награду. В этой версии XP показывает накопленный опыт и участвует в учебных достижениях; покупок и расходов больше нет.

Коллекция: 84 игрушки — 12 животных по 7 вариаций. 82 игрушки выдаются за практику соответствующих эпизодов, две итоговые награды — за весь курс и всю практику. Индивидуальное распределение игрушек и уже полученные награды сохраняются при обновлении.

Прогресс, настройки и черновики хранятся локально; автоматической синхронизации между устройствами нет. Экспорт/импорт JSON находится в настройках. Импорт старых копий поддерживается, игровые разделы из них не восстанавливаются.

## Файлы проекта

`course.js`, `practice.js`, `warmup.js`, `reference-data.js` — учебные данные; `learning-core.js` — банк тренировок и проверки; `app.js`, `learning-ui.js`, `practice-ui.js`, `plush.js` — интерфейс и сохранения. Четыре CSS-файла отвечают за основной дизайн, учебные экраны, коллекцию и редизайн главной/профиля. `sw.js` управляет офлайн-кэшем; `manifest.webmanifest` — установкой на телефон.

Результаты проверки текущей версии: [docs/QA.md](docs/QA.md) и `docs/qa-results.json`. `LICENSE`, лицензия шрифта и документы источников сохранены.
