# Afterhours — вечерний английский

Готовое автономное веб-приложение в стиле вечернего киноклуба. Тёмная сливовая палитра, тёплые янтарные акценты, 18 атмосферных фотографических сцен, крупные тексты и аватар ведущей. Работает без сборки, npm, API-ключей и сервера приложений.

## Запуск на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Распакуйте ZIP. Загрузите **содержимое архива в корень репозитория**: `index.html`, `app.js`, `course.js`, `styles.css`, `sw.js`, `manifest.webmanifest`, папки `assets` и `docs`. Сохраните структуру папок. Через браузер загружайте в три партии: сначала файлы из корня, затем целиком папку `assets`, затем `docs`. GitHub допускает до 100 файлов за один раз; в `assets` ровно 100 файлов. Не загружайте ZIP вместо файлов.
3. В **Settings → Pages → Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`. Сохраните.
4. Откройте адрес, который появится в Pages. Первое опубликование обычно занимает несколько минут.

Все пути относительные: приложение поддерживает адрес `https://имя.github.io/репозиторий/`. Полезно сохранить `.nojekyll`; приложение не требует Jekyll.

Для локального просмотра запустите в папке приложения `python3 -m http.server 8000` и откройте `http://localhost:8000`. Простое открытие HTML через `file://` не включает PWA и офлайн-кэш.

## Учебная основа

Программа **не составлена с нуля**. Сохранены все 52 урока **VOA Let’s Learn English Level 1** и 30 уроков **Level 2**, их оригинальный порядок, диалоги и ссылки на материалы преподавателей. Оба курса созданы сертифицированными американскими преподавателями. 15 «сезонов» объединяют соседние уроки только для удобной навигации.

В приложении 718 заданий: оригинальные вопросы VOA на понимание, 76 коротких оригинальных аудиозаписей VOA, чтение сцен, работа с определениями из преподавательского словаря, сборка реплик, заполнение пропусков, восстановление диалогов, диктант и письменные фрагменты. Первый вопрос в 79 уроках взят из оригинального теста VOA. Остальные короткие форматы адаптированы по исходным репликам и словарю; они не выдаются за официальный тест VOA. Для всех 82 уроков доступна письменная практика по преподавательским сборникам. В Level 2 №24 использована письменная часть упражнения Giving Advice.

Источники и условия использования — в [docs/SOURCES.md](docs/SOURCES.md). Поурочная карта — `docs/source-map.json`; ключи оригинальных вопросов — `docs/quiz-key.json`.

Метки A1–A2 и A2–B1 — приблизительный ориентир сложности, а не официальное соответствие VOA уровням CEFR. Сертификат уровня не выдаётся. По умолчанию точка старта — урок 17 первого курса, чтобы не повторять самые простые знакомства. В профиле можно выбрать начало курса или Level 2; любой эпизод доступен в коллекции.

## Функции

- Одно задание на экране; проверка, пояснение, следующая сцена.
- Очки 10–25 XP в зависимости от формата. Очки за конкретное задание начисляются один раз. Повторения доступны без ограничения.
- Сохранение текущего задания, черновика, выбранных слов и ответа сразу после изменения.
- Профиль, прогресс по курсам и сезонам, цель на день, серия дней занятий, 9 достижений.
- Повторение ошибок и личный письменный дневник.
- Экспорт и восстановление прогресса в JSON, подтверждение сброса данных.
- Настройки скорости диктанта, звуков и анимаций; поддержка системного уменьшения движения.
- Установка на домашний экран как PWA. После успешной первой загрузки офлайн доступны интерфейс, уроки, картинки и включённые короткие записи VOA.

## Важные особенности

Прогресс хранится в **этом браузере на этом устройстве**, через `localStorage`. Закрытие вкладки его не удаляет. Автоматической синхронизации между устройствами нет: для переноса используйте экспорт/импорт в профиле. Очистка данных сайта удалит прогресс, поэтому сохраняйте резервные копии.

Начальные 65 XP — перенесённая отметка из предыдущей учебной переписки. Они не означают прохождение уроков VOA. Сброс в профиле начинает счёт с нуля.

Проверка ответов локальная и работает по исходным репликам. Регистр, пунктуация и распространённые сокращения не мешают оценке. В заданиях на восстановление требуется реплика оригинала: приложение не оценивает все возможные перефразировки. Свободный текст в дневнике сохраняется **без автоматической оценки грамматики**. Никакого скрытого обращения к ИИ или платному сервису нет.

Короткие исходные аудиозаписи включены в архив. Диктанты из отдельных реплик озвучиваются английским голосом устройства; наличие этого голоса зависит от браузера и ОС. Если озвучка недоступна, есть текстовый режим без XP за аудирование. Полные исходные записи и внешние преподавательские материалы по ссылкам требуют интернет.

Марго — вымышленная ведущая с предоставленным пользователем аватаром. Это не реальная переписка с актрисой и не приложение с её участием.

## Структура

- `index.html` — оболочка и навигация.
- `styles.css` — адаптивный дизайн, компоненты и анимации.
- `app.js` — уроки, проверка, профиль, сохранение, резервные копии.
- `course.js` — содержание 82 уроков и 718 заданий.
- `assets/` — локальные шрифты, изображения, значки, записи VOA.
- `sw.js` — офлайн-кэш, включая поддержку диапазонов байтов для аудио.
- `manifest.webmanifest` — установка PWA.
- `docs/` — источники, ключи, карта содержания и отчёт проверки.

После изменения файлов обновите версию кэша в `sw.js` (строка `CACHE`), чтобы существующие установки получили новые файлы. Перенос сайта на другой домен или путь создаёт другое хранилище прогресса; сначала экспортируйте его.

## Проверка

Проверено в Chromium через настоящие элементы интерфейса: прохождение разных уроков и типов заданий, ошибки и повторение, перезагрузка на незавершённом и уже проверенном ответе, защита от повторного XP, экспорт/импорт, отмена сброса, анимации и reduced motion, адаптивность 320–1440 px, GitHub-подобный подпуть и офлайн-аудио. Подробнее — `docs/QA.md`. На реальных iPhone/Android тестирование не проводилось.

Инструкции публикации проверены по официальной документации GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site и https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository .
