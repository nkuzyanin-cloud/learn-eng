# Исправление перехода между уроками

## Причина

В прежней версии один незавершённый state.active блокировал все другие новые уроки и перехватывал главную. При этом повторные уроки оставались доступны. Поэтому черновик «Сокращение бюджета» мог оставаться активным, пока пользователь завершал первые пять эпизодов, и закрывать шестой эпизод первого модуля. Это ошибка навигации, а не требование программы или лимит на день.

## Поведение после обновления

- Все 82 урока доступны независимо от других незавершённых попыток.
- Текущая попытка остаётся в active, при переключении переносится в lessonDrafts по ID урока. Сохраняются этап повторения, страница теории, индекс задания, ответ, выбор, собранные слова, ошибки, заработанный XP и startXP.
- Карточка каждого незавершённого урока показывает «Продолжить». Начало другого урока не стирает прежний черновик.
- studyLesson хранит выбранный учебный маршрут. После завершения приложение предлагает следующий непройденный эпизод по порядку курса. Повтор завершённого урока не меняет маршрут.
- При первом обновлении старой копии маршрут восстанавливается по последнему завершённому уроку. Если старый active указывает на другой эпизод, он сохраняется отдельно и больше не перехватывает главную. Если завершённых уроков нет, используется active или выбранная точка старта.
- Новая установка по умолчанию начинается с первого урока. Существующие настройки сохраняются. Явное изменение точки старта в настройках меняет маршрут и сохраняет текущий черновик.
- XP по-прежнему выдаётся один раз по прежнему ключу задания. Уроки, награды, коллекция и учебные материалы не перенумерованы.
- celebratedLevel предотвращает повторное празднование уже показанного повышения, когда пользователь завершает старую отложенную попытку. Пороги и рамки уровней не изменены.
- Экспорт/импорт включает отдельные черновики и маршрут; копии прежнего формата поддерживаются.

## Установка

Загрузить содержимое Afterhours-lesson-navigation-fix.zip поверх последней версии проекта, сохранив относительные пути. Ничего удалять не требуется. Архив содержит только исправленные файлы и документы; он не заменяет всю папку проекта.

Дождаться публикации и повторно открыть приложение. Версия офлайн-кэша обновлена, старый кэш заменяется автоматически. Не очищать данные сайта и не нажимать «Начать заново»: это удаляет локальный прогресс и для исправления не требуется.
