# Повышение уровня после урока

Экран слегка затемняется и размывается. В центре — аватар с прежней рамкой и уровнем; полоса заполняется до конца, появляется один тёплый импульс света, раскрывается новый уровень. На порогах 4, 7, 10, 13, 16 меняется рамка; при остальных повышениях сохраняется существующая рамка. После раскрытия полоса заполняется до фактического остатка XP. Максимальный уровень имеет полную полосу и подпись «Максимальный уровень».

Последовательность занимает около 2,5 секунды после готовности локальных изображений. «Продолжить» доступна во время эффекта и после него; она сразу возвращает к результату урока. Фон не получает сплошной белой вспышки. Размытие — фон native dialog; если браузер не умеет размывать его, остаётся затемнение.

## Данные и момент показа

Новая активная попытка хранит startXP — весь накопленный опыт на момент начала урока. Это поле сохраняется вместе с черновиком и проходит проверку при загрузке/импорте. Поэтому XP, полученный до выхода из приложения, учитывается при последующем завершении той же попытки. Текущие XP и completed сохраняются до запуска анимации. Сам визуальный модуль не записывает прогресс и не создаёт награды.

Показ нужен только после завершения нового урока, если итоговый уровень выше уровня при старте. Если порог пересечён раньше последнего задания, повышение всё равно показывается в конце. Несколько пересечённых порогов дают один переход до итогового уровня. Повторные уроки, отдельная практика, разговорный экспорт, импорт/восстановление старого опыта и обычное открытие профиля не создают очередь празднований.

Повод для показа хранится только в памяти текущей вкладки и потребляется один раз. Reload во время анимации оставляет сохранённый результат и не повторяет эффект. У прежней незавершённой попытки без startXP новая точка отсчёта устанавливается при возвращении в урок: прошлые повышения не воспроизводятся задним числом.

## Прерывания и доступность

Кнопка, Escape, навигация и уход со страницы отменяют анимации и снимают блокировку прокрутки. При сворачивании вкладки остаётся готовый итоговый экран, чтобы после возвращения не видеть зависшую вспышку. Отключённое движение в приложении или prefers-reduced-motion сразу показывает результат без вспышки. Если Web Animations API отсутствует или эффект не удалось выполнить, доступен тот же итоговый экран.

Диалог использует showModal, поэтому фон не принимает клики и фокус. У полосы есть доступные значения, итоговый уровень объявляется через status; закрытие возвращает фокус к результату урока. На коротком экране диалог прокручивается, заголовок не обрезается сверху. Имена экранируются как текст.

## Файлы

Два новых runtime-файла — level-celebration.js и level-celebration.css. Рамки используются из assets/profile, те же, что и в профиле. index.html подключает модуль перед app.js; sw.js включает обе новые зависимости и меняет версию кэша (149 URL). Новых картинок, внешних API и библиотек нет. После заполнения офлайн-кэша эффект не требует сети.

Архив обновления содержит только новые/изменённые файлы, удаления не нужны. Данные сайта не очищать. Учебные файлы, пороги XP, коллекция и распределение игрушек не меняются.
