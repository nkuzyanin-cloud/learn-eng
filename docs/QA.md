# Проверка исправления навигации уроков

Проверено в Chromium с настоящим service worker и локальным сохранением на адресе /english/. Машинный отчёт: qa-results.json. Это функциональная проверка, не методический аудит программы.

- В установленной прежней версии воспроизведён сценарий со скриншотов: первые пять эпизодов завершены, 730 XP, активный «Сокращение бюджета», шестой урок закрыт.
- После обновления главная показывает первый модуль, 5 из 6 эпизодов и доступный шестой урок. Старый черновик сохраняется отдельно. Завершения, XP, настройки, практика, игрушки, записи и активность сравниваются с сохранением до обновления.
- Переключение между тремя попытками сохраняет страницу теории и черновики повторения. Повторная загрузка восстанавливает выбранную попытку без дополнительного XP.
- Полное прохождение шестого эпизода: три задания повторения без XP, теория, все проверяемые задания, ровно 135 XP; итог 865 XP. Первый модуль завершён. Следующий эпизод — v1-07. Повышение до уровня 2 показывается один раз.
- Завершение старого отложенного урока не повторяет уже показанное повышение уровня.
- Настройка точки старта работает в обе стороны и сохраняет текущую попытку. Все 82 карточки доступны без экрана блокировки.
- Настоящий экспорт и импорт файла сохраняют черновики, маршрут и прежние данные. Приведение полей к формату валидатора сохраняет содержимое ответов.
- Обновление непосредственно предыдущей PWA заменяет кэш 149 URL на новую версию. Старый XP сам не вызывает анимацию. Выбор карточки и восстановление черновика после перезагрузки работают без сети.
- В каждом из 82 уроков через интерфейс проверен последний шаг: точная награда, завершение и сохранение результата.
- Повторно пройдены 20 сценариев анимации: все 15 порогов, полный новый урок, повтор без XP, reload, отключённые анимации, Escape, закрытие, навигация, сворачивание, несколько пересечённых уровней, max-level, офлайн, отсутствие Web Animations API и блокировка sessionStorage.
- Проверены 20 сочетаний страницы и ширины для главной, модуля, каталога модулей и всех уроков; горизонтальной прокрутки нет. В анимационных проверках дополнительно проверены короткие экраны и длинные имена.
- Все JS проходят синтаксическую проверку. Все URL кэша существуют. Учебные данные, проверки ответов, практика, разминки, коллекция, обложки и графика рамок остались прежними. Сценарии проходят без ошибок JavaScript и отсутствующих файлов.

Физический iPhone и Safari в этом окружении не тестировались.
