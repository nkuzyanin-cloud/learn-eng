# Проверка текущей версии

Анимация проверена в Chromium с настоящим service worker, на адресе /english/, с локальными копиями прогресса. Машинный отчёт: qa-results.json. Проверки функциональные; они не являются методическим аудитом содержания всех уроков.

- Настоящее повышение 3 → 4 через проверку последнего задания и завершение: рамка 1 → 4, полный старый прогресс, вспышка и точные 7 XP на новой полосе. Новый уровень и completed сохранены до показа.
- Полный новый урок: теория, каждый проверяемый шаг, запись startXP при начале, переход в уровень 4 и верный остаток. Отдельно проверен reload после принятого ответа перед завершением.
- Все 15 порогов уровней через завершение реального задания: правильная рамка, состояние без её смены, максимальный уровень. Порог, уже пересечённый ранее в сохранённой попытке, обнаруживается в конце после reload.
- Несколько пересечённых уровней дают один итоговый экран. Урок без повышения и полный повторный урок показывают обычный результат без дополнительного XP.
- Старые активные попытки без startXP получают точку отсчёта при возвращении, без празднования уже накопленного XP. Новая попытка сохраняет startXP через теорию, reload и JSON validation.
- Продолжить во время эффекта, Escape, навигация в профиль, reload прямо во время заполнения, сворачивание в момент раскрытия. Нет зависшего света, лишних анимаций, повторных показов или сохранённой блокировки прокрутки.
- Отключённое движение в приложении и в ОС — готовый экран без анимации. Отсутствие Web Animations API — безопасный итоговый экран. Блокировка sessionStorage не мешает сохранению completed и показу текущего результата.
- 10 сочетаний ширины/высоты (320, 375, 390, 768, 1440 × 568, 844) с длинным именем: нет горизонтальной прокрутки. Дополнительно повёрнутый телефон 844×390 и крайне короткий экран 320×320: заголовок доступен, кнопка прокручивается в видимую область.
- Обновление непосредственно предыдущей установленной PWA: кэш 147 URL заменяется на 149, настройки и остальные данные сохраняются, старый опыт не вызывает анимаций. Полный эффект работает офлайн, рамки декодируются из локального кэша.
- Регрессия предыдущего обновления: два полных новых урока за один день, текстовое аудирование с ошибкой/исправлением и reload, разминка без XP, полный повтор без XP, старые письменные черновики и сохранённое последнее задание.
- Во всех 82 уроках через интерфейс проверен последний шаг: счётчик, полная награда, завершение без свободного письменного шага.
- Реальный экспорт JSON и импорт через файл сохраняют состояние. 60 сочетаний страницы/ширины и длинные имена — без горизонтальной прокрутки. Шесть рамок профиля, общая графика достижений, ссылки, max-level профиль и начало урока офлайн.
- Все JS-файлы проходят синтаксическую проверку. Все 149 URL кэша существуют. 82 урока, 568 текущих проверяемых заданий, исторические ключи и 16 порогов не меняются. Учебные данные, learning-core, разминки, отдельная практика, модульные обложки и файлы коллекции побайтово прежние.
- В успешных браузерных прогонах нет ошибок JavaScript и отсутствующих файлов. Визуально проверены заполнение старой полосы и итоговые экраны с рамками 4 и 10.

Физический iPhone и Safari в этом окружении не тестировались. Плавность на конкретном устройстве нужно проверить после установки; предусмотрен режим без движения. Функциональные результаты из предыдущего релиза модулей сохранены в прежних документах, текущий отчёт не выдаёт их за новый прогон.
